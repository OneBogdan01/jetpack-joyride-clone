<p>This is my second entry for the&nbsp;<a rel="nofollow noopener" href="https://20_games_challenge.gitlab.io/">20 games challange</a>&nbsp;as  a jetpack joyride&nbsp;clone. I have reused the whole&nbsp;from flappy bird and repurposed it for this project. The biggest roadblocks were that the particle system for the compatibility render is seriously underwhelming in terms of features. The physics 2D for AnimatableBody2D was another weird quirk of the Godot engine that I had to deal with.&nbsp;</p>
<p><br>All in all I am happy how it turned out, I also worked on some utilities scripts that I plan to reuse in the next projects.</p>
<h2>Features</h2>
<ul><li>The background uses the parallax node</li><li>Game state and scene loading: intro menu, game over screen and a credits menu!</li><li>Highscore saving between sessions via&nbsp;<a rel="nofollow noopener" href="https://docs.godotengine.org/en/stable/classes/class_configfile.html">ConfigFile</a></li><li>The game gets progressively faster and harder by accumulating the distance traveled.</li></ul>
