This is my second entry for the 20 games challange as a jetpack joyride clone. I have reused the whole from flappy bird and repurposed it for this project. The biggest roadblocks were that the particle system for the compatibility render is seriously underwhelming in terms of features. The physics 2D for AnimatableBody2D was another weird quirk of the Godot engine that I had to deal with. 


All in all I am happy how it turned out, I also worked on some utilities scripts that I plan to reuse in the next projects.
Features

    The background uses the parallax node
    Game state and scene loading: intro menu, game over screen and a credits menu!
    Highscore saving between sessions via ConfigFile
    The game gets progressively faster and harder by accumulating the distance traveled.
